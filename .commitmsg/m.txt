feat(pipeline): contract-executor registry, and a gate that measures the split

B2 checkpoint A completed, plus the convergence report's grep gate.

**The registry.** `runtime_contract_registry` mirrors `workflow_adapter_registry`:
one place answering "can this runtime execute this step?", rather than that
being a property of whichever `match` arm a reader happens to find. It also
separates two errors that have different fixes — a contract absent from the
registry is a package this *build* cannot run (the fix is a version), while a
registered contract left unhandled means the host reached the step without the
resources for *this request*. Reporting both as "unimplemented" sends an
operator hunting a bug that is really a mismatch.

**The gate.** `shape_dispatch_gate` bans `is_workflow`, `lowered_workflow`,
`canonical_decode` and `WorkflowShape` outside an explicit allowance, because
package-shape dispatch is easy to reintroduce and nearly invisible in review:
one `if engine.is_workflow()` restores the split without touching a single
assertion. The allowance is the B2 remaining-work ledger, written down, and it
may only shrink.

Writing it immediately paid for itself. I had accounted for fifteen files by
inspection; the gate found **eight more** — `decode_loop.rs` (25 uses),
`native_decode/mod.rs`, `native_speculative.rs`, `session.rs`, `lib.rs`, and
three server routes (`completions`, `sessions`, `speech`). Those are callers the
convergence work has to move, and I would have discovered them one compile error
at a time, late, while believing the surface was smaller than it is.

A second test keeps the ledger honest: an allowance naming a deleted file is a
rule nobody is subject to, and it would outlive the work it was tracking.

I am deliberately *not* claiming these symbols are gone. They are counted, and
the count is a test. When the convergence lands they stop existing and this gate
becomes trivially true, which is the intended end state.
