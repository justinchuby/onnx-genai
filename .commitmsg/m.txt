feat(engine): the decode step becomes a node executor, not a loop

B2 checkpoint 2: the runtime's decode and token-policy steps are now a
`WorkflowNodeHost` implementation, so the fused decode session is something an
interpreter *drives* rather than something that drives itself.

`DecodeNodeHost` advances exactly one node per call — a decoder forward pass
(with its device greedy/sampling fast paths and paged KV), or the token policy
(processor chain, sampler, logprobs, KV commit, stop detection). It holds
nothing about the loop. The only state spanning nodes within an iteration is the
logits the decode node produced and the policy node consumes, and a workflow
applying its policy before any decode says so rather than silently scoring
nothing.

`step_canonical_body` no longer contains the step logic; it walks the declared
body and calls the executor. So there is one implementation of "what a decoder
step is", reached today by the body walker and — once `Engine::generate*` moves
across — by the interpreter's own node dispatch, through the same
`execute_contract_node` seam checkpoint 1 added.

**The decoder now declares a contract.** `onnx-genai.autoregressive-decode` sits
*alongside* the component's ONNX artifact rather than instead of it: the package
still says which graph the step runs, and the contract says what the step *is*.
A runtime holding a fused session for that contract supplies it as the executor;
a runtime without one invokes the artifact generically. That is what lets the
optimized path be a node inside a workflow instead of a second loop beside one —
without the package having to know which runtime will execute it.

An earlier draft of the body walker re-borrowed the token callback per node with
a `transmute`. That was a lifetime workaround standing in for a design problem,
so the host carries two lifetimes instead — one for the borrows it holds, one
for the callback's own — and the transmute is gone.

Verified: 73/73 engine targets; **all five real foundry models byte-identical to
the pre-change baseline**, which is what shows the executor split changed no
token on any real decoder; fmt; clippy `-D warnings`.
