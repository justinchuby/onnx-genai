```rust
fn reverse_string(s: &str) -> String {
    s.chars().rev().collect()
}

fn main() {
    let original_string = "hello";
    let reversed_string = reverse_string(original_string);
    println!("Original: {}", original_string);
    println!("Reversed: {}", reversed_string);
}
```

### Explanation:
- The function `reverse_string` takes a reference to a string `s` as its parameter.
- It uses the `chars()` method to get a mutable iterator over the characters of the string.
- The `rev()` method is then applied to the iterator to reverse the order of the characters.
- Finally, the `collect()` method is used to convert the iterator back into a string.
