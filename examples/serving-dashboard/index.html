Opened from disk

This page has to be served by the onnx-genai server.

It reads live telemetry from the server over HTTP. Opened as a file:// URL there is no server to read from, and the browser blocks its JavaScript modules before they run.

Run the server, then open the demo

cargo build --release -p onnx-genai-server

ONNX_GENAI_EP=cpu ./target/release/onnx-genai-server \
  --model models/qwen2.5-0.5b-scatter-v2 \
  --model-id qwen-scatter \
  --addr 127.0.0.1:8123 \
  --enable-debug-endpoints

Then open http://127.0.0.1:8123/demo/ — the server serves this page itself.
