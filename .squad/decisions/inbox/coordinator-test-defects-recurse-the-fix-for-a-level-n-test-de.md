### 2026-08-19T12-22-13: Test defects recurse: the fix for a level-N test defect is itself level-N+1 material and must be mutated before it is reported
**By:** coordinator
**What:** Test defects recurse: the fix for a level-N test defect is itself level-N+1 material and must be mutated before it is reported
**References:** issue #1186, PR #1440, PR #1448, PR #1454, PR #1462, reviewer-protocol, measurement-discipline, test-discipline
**Why:** Across four review rounds on the Phase 6 nxmem plugin ABI (PRs #1440, #1448, #1454, #1462), three rejections and one approval, the defect that caused each rejection moved up exactly one level of indirection each time. The sequence is worth recording because it is not specific to this artifact:

1. #1440 — fixtures that lied. A "short struct" test fixture was actually full-size, so the over-read it claimed to exercise was unobservable.
2. #1448 — assertions bound to the counter a fix increments rather than to the behaviour it performs. Deleting `core::mem::forget(Arc::clone(&self.module))` while leaving `FORCED_MODULE_LEAKS.fetch_add` in place left 101 tests green. Production code was correct; the reviewer asked for zero production changes and rejected purely on surviving mutations.
3. #1454 — assertions correctly moved onto a proxy (`MODULES_UNMAPPED`, incremented in `Drop for PluginModule`, an exact `dlclose` proxy because `library` is declared last). But the proxy's PLACEMENT was unpinned: every test asserting the counter moved went through `try_unload`, every test asserting it did not move went through the plain drop path, and no test observed an unmap via the drop path. Relocating the increment re-opened the headline fix at 111/0 green.
4. #1462 — APPROVED. Anchored the proxy, then found the next level inside its own fix (deleting `declares_its_own_level` from the new mechanism made the anchored assertion vacuous again) and closed it structurally by reading the observable out of the published struct rather than from a flag set beside the publishing code.

THE RULE: when you fix a level-N test defect, the fix is itself level-N+1 material. Mutate your own new test infrastructure with the same hostility you applied to production code, BEFORE reporting, not after. In round 4 that is the only reason the fifth level was caught — the author ran its full mutation series against its own mechanism expecting it to be clean, and it was not.

COROLLARY ON EQUIVALENT MUTANTS AND DECLINING TO CLOSE: a disclosed survivor with a sound equivalence proof is a mark of quality, not a defect. Two rounds earned explicit credit for declining to build a mechanism whose only purpose was to make the author's own mutation table look clean (round 3 O14, round 4 O10 — the latter because its only observable was undefined behaviour). Conversely, round 4 corrected a reviewer's finding by proving an equivalence on the code (one construction site, same `minor` fed to both the guard and the clamp) rather than writing a test for an unreachable branch, and the reviewer accepted it. Prefer proving equivalence over manufacturing coverage.

COROLLARY ON HONESTY: all four authors self-reported accurately and were verified line by line; three were still rejected. Honest reporting is necessary but not sufficient. The bar is whether the tests can fail, not whether the report is truthful.
