### 2026-09-01: Session authority is an opaque value, never a Cargo feature
**By:** Iran
**What:** Executor identity allocation, provider-template binding, and finalization-proof issuance require a borrow of `ExecutorArtifactSessionAuthority`, an opaque zero-sized ep-api token with a private field and no constructor. The session executor owns the sole production instance in a private static and never returns it. Integration tests that must drive provider internals construct a private token only inside their test binary; ordinary `gpu-tests` library builds expose no issuer. The additive `runtime-session-authority` feature is removed.
**Why:** Cargo feature unification answers which code is compiled, not which dependency caller is trusted. A private capability value makes authority possession explicit in the type system and independent of every production feature combination, while preserving provider-owned immutable policy, session-owned executor/generation issuance, typed Disabled/Enabled finalization, and the existing lifecycle contracts.
