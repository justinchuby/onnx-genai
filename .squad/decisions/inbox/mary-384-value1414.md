**By:** Mary
**What:** `value#1414` is the named graph input `past_key_values.0.recurrent_state`, a fixed rank-4 persistent CUDA binding. The embedded `com.microsoft::LinearAttention` function contains a `Scan`; after function inlining, its body lexically captures that outer recurrent-state input. **Why:** Persistent device I/O is a first-class source of graph values and must be visible at every materialization boundary, including nested `If`/`Loop`/`Scan` lexical captures. The general fix applies to arbitrary externally bound captures, not recurrent-state names or Qwen-specific geometry.
