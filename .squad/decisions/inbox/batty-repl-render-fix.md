### 2026-07-30: REPL rendering is append-only; no inline viewport
**By:** Batty
**What:** The interactive `run` renderer no longer uses ratatui's inline viewport. Reasoning detection still uses the rendered current-generation prompt, streaming and final history-splitting still share `ReasoningStream`, but live output now writes append-only text with ANSI dim/reset for reasoning and prints final stats after the turn. The ratatui dependency was removed from the CLI.
**Why:** Reedline owns the prompt/input line and ratatui's inline viewport also tried to own cursor position and scrollback. On later turns, activating the viewport after reedline echoed the submitted prompt could reserve rows at the input line, so streamed model output overwrote `>>> user input`; finish also leaked blank/status rows into scrollback. Append-only output is structurally safe: it never moves the cursor up, never calls `insert_before`, never rewrites scrollback, and therefore cannot eat submitted input or prior output.
