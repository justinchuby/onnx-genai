## Summary

Fixed two memory-safety defects in the absent optional-output machinery:

**B1 — 2× heap buffer overflow:** Scratch buffers for absent optional outputs were
sized from the slot's declared dtype byte size (2 bytes for f16/bf16) but `TensorMut`
was hardcoded to `Float32`, so kernels wrote `numel × 4` into a `numel × 2` buffer.
Fix: scratch dtype derived from `output_dtypes[slot]`, buffer sized at
`max(byte_size, 8)` per element, `TensorMut.absent` flag added, fail-closed on
`Undefined` dtype.

**B2 — Routed path positional compaction:** Fused multi-node path skipped allocation
for absent slots but iterated all sinks via shortened iterators, causing panic or
misrouting on any fused node with omitted outputs. Fix: `RoutedSlotKind` enum
(Ort/Buffer/Absent) — one entry per slot, indices aligned end-to-end.

**Durable lesson recorded:** Deferrals must be backed by evidence. Nabil's B2 deferral
cited `MemoryDevice_GetDeviceId` as unavailable — this API was present in
`bindings.rs:6309` and already in use. Third false "API does not exist" claim on this PR.
