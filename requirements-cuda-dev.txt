# CUDA runtime libraries for building and testing the native CUDA EP.
#
#   python -m pip install -r requirements-cuda-dev.txt
#
# These are NVIDIA's redistributable runtime wheels. They are the supported way
# to get cuBLAS/NVRTC/cudart without installing a full CUDA toolkit, and the
# CUDA EP's loader already knows how to find them: it recovers a wheel root from
# any `<root>/nvidia/<component>/{bin,lib}` entry on the loader path, or from
# `NXRT_CUDA_WHEEL_ROOTS`. See `crates/onnx-runtime-ep-cuda/src/dynamic_library.rs`.
#
# ---------------------------------------------------------------------------
# The major version here MUST match the crate's selected CUDA feature.
# ---------------------------------------------------------------------------
#
# `onnx-runtime-ep-cuda` defaults to `cuda-13000`, and that feature is forwarded
# to `cudarc`. cudarc generates the shared-library names it will dlopen from its
# *build-time* CUDA version, so a `cuda-13000` build searches `nvrtc64_130_0.dll`
# and never looks for a CUDA 12 file. Installing a CUDA 12 wheel against a
# CUDA 13 build therefore fails at first kernel compile with
#
#     Unable to dynamically load the "nvrtc" shared library
#
# even though the file is present and on PATH. That is a version mismatch, not a
# missing name — our own loader searches both spellings and finds it fine; it is
# cudarc's separate list that does not. If you change the crate's CUDA feature,
# change the wheel major version here to match.
#
# NVIDIA consolidated these onto unsuffixed names carrying every CUDA line, so
# the version pin (not the package name) selects the CUDA major. That also
# changed the on-disk layout, from `nvidia/<component>/{bin,lib}/` to
# `nvidia/cu13/{bin,lib}/<arch>/`; the loader understands both. The older
# `-cu12` / `-cu13` spellings still exist, but `-cu13` is a placeholder with no
# real release, so do not reach for it.
#
# Nothing here needs to be on PATH. Point the loader at the install root:
#
#   NXRT_CUDA_WHEEL_ROOTS=<the --target directory, or your site-packages>
#
# or install into the active virtualenv, whose site-packages is already on the
# loader path.

# NVRTC — runtime compilation of the EP's fused kernels. Required.
nvidia-cuda-nvrtc==13.3.33

# cuBLAS / cuBLASLt — the GEMM backend. Required.
nvidia-cublas==13.6.0.2

# CUDA runtime (cudart) and, importantly, the headers NVRTC #includes
# (`cuda_fp16.h`, `cuda_bf16.h`). Without these the f16/bf16 kernels fail to
# compile at runtime with "require cuda_fp16.h and cuda_bf16.h". Required.
nvidia-cuda-runtime==13.3.29

# cuDNN — only needed for the cuDNN-backed softmax/reduce/conv/pool path. The
# EP dlopens it lazily and runs without it, so this is optional; uncomment if
# you are exercising those kernels. Note this one still uses the -cu13 suffix,
# because the unsuffixed `nvidia-cudnn` is a placeholder with no real release.
# nvidia-cudnn-cu13==9.24.0.43
